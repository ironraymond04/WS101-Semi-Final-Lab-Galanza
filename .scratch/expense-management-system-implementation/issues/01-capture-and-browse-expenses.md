# 01: Capture and browse expenses

**What to build:** A single user can manually record an expense, find it in their expense history, and still see it after reopening or reloading the app on the same browser/device.

**Blocked by:** [Expense record and category model](../../expense-management-system/issues/01-expense-record-and-category-model.md) and [Web stack and run target](../../expense-management-system/issues/03-web-stack-and-run-target.md).

**Status:** ready-for-agent

- [x] A user can record an expense using the fields and category behavior agreed for the MVP.
- [x] A user can browse the saved expense history and recognize each recorded expense.
- [x] Saved expenses remain available after reloading or reopening the app in the same browser/device.
- [x] The capture and history workflow works at desktop and phone-sized browser widths.
