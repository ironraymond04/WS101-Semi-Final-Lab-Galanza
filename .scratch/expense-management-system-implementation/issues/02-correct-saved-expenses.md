# 02: Correct saved expenses

**What to build:** A user can correct or remove a saved expense according to the agreed rules, and see the resulting expense history remain accurate.

**Blocked by:** [01: Capture and browse expenses](01-capture-and-browse-expenses.md) and [Expense correction and validation](../../expense-management-system/issues/04-expense-correction-and-validation.md).

**Status:** ready-for-agent

- [ ] A user can edit or delete a saved expense as allowed by the agreed correction rules.
- [ ] Invalid corrections are handled with the agreed validation and do not silently corrupt saved data.
- [ ] After a correction or deletion, the expense history reflects the saved result.
- [ ] Changes remain available after reloading or reopening the app on the same browser/device.
