# 03: Review spending summaries

**What to build:** A user can review spending totals and breakdowns over the agreed periods, based on their saved expenses.

**Blocked by:** [01: Capture and browse expenses](01-capture-and-browse-expenses.md) and [Expense summary definitions](../../expense-management-system/issues/02-expense-summary-definitions.md).

**Status:** ready-for-agent

- [ ] A user can view the agreed expense totals for the default and selectable periods.
- [ ] A user can view the agreed breakdowns using the selected expense and category model.
- [ ] Summary values match the expenses saved for the selected period and grouping.
- [ ] Adding saved expenses is reflected in the displayed summaries.
- [ ] The summary view works at desktop and phone-sized browser widths.
