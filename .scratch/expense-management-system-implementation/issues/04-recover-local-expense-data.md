# 04: Recover local expense data

**What to build:** A user can use the agreed recovery or portability controls to protect, move, restore, or deliberately clear expense data stored on the same browser/device.

**Blocked by:** [01: Capture and browse expenses](01-capture-and-browse-expenses.md) and [Local data recovery and portability](../../expense-management-system/issues/05-local-data-recovery-and-portability.md).

**Status:** ready-for-agent

- [ ] The agreed data recovery, portability, or reset controls are available to the user.
- [ ] The user receives the agreed confirmation and feedback for any export, restore, backup, or destructive reset operation.
- [ ] The controls preserve or remove expense data according to the agreed behavior.
